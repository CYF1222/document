\subsection{优点}

\begin{enumerate}
    \item 采用Dijkstra算法对地图进行预处理，简化路径，避免计算量过大；
    \item 通过负重重量进行回溯路径、采购数量等，记录方案详细内容，从而找到最优解；
    \item 第二问中引入马尔可夫模型参与决策，引入概率这一因素建立了基于期望的最大化收益模型，
        将不确定的问题通过随机确定的方式化解；
    \item 第三问采用蒙特卡洛算法随机模拟天气，从而给出一般天气状况下的最佳方案；
    \item 第三问先进行数值分析，确定合作而非竞争的博弈关系，将多人问题最优解降维为单人最优路径规划，
        并引入联盟稳定性指标进行验证。
\end{enumerate}

\subsection{缺点}

\begin{enumerate}
    \item 运用蒙特卡洛进行天气预测时，必须给定各天气概率，预测结果准确性有待提升；
    \item 问题三采用整体收益最大化为目标，个体收益不一定最大，且未考虑多人错峰挖矿的情况；
    \item 问题三仅限于小基数玩家的讨论，未考虑大基数玩家的情况，模型普适性有待提高。
\end{enumerate}
